Supporto

Tethera 1.2 · Mac, iPhone, iPad, Android, Windows e Linux

Scrivici: enricofanucchi@gmail.com. Rispondiamo di solito entro due giorni lavorativi.

Indica la versione dell'app (in fondo alle Impostazioni), il dispositivo e il sistema, e il server VNC del computer remoto (per esempio Condivisione schermo del Mac, TigerVNC, wayvnc, RealVNC). Non inviare mai password o chiavi private.

Primi passi

  1. Attiva la condivisione dello schermo sul computer remoto: sul Mac in Impostazioni di Sistema › Generali › Condivisione › Condivisione schermo; su Linux e Windows con un server VNC.
  2. In Tethera scegli Aggiungi server e inserisci indirizzo e porta (di solito 5900). I computer vicini compaiono da soli nella sezione Server.
  3. Fai clic sul server: si apre la sessione nella sua finestra.

Domande frequenti

Come proteggo la connessione?

Nella scheda del server attiva Usa tunnel SSH: schermo e tastiera viaggiano cifrati. Il lucchetto nella barra della sessione diventa verde. Lo stesso collegamento SSH serve anche a trasferire i file.

Come mi collego da fuori casa?

Con Tailscale o un'altra VPN usa l'indirizzo VPN del computer. Senza VPN imposta Fuori casa con un gateway SSH sempre acceso nella tua rete (per esempio un Raspberry Pi): non serve aprire porte VNC sul router.

Come invio file al computer remoto?

Trascina i file sulla finestra della sessione, oppure apri File nella barra della sessione. Serve SSH attivo sul computer remoto e il tunnel SSH nella scheda del server.

Il computer remoto è un Mac: come uso le scorciatoie?

Su Windows e Linux Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+A e Ctrl+Z diventano le scorciatoie con ⌘ sul Mac. Ctrl+V incolla prima il testo copiato sul tuo computer.

Come sveglio un computer spento?

Inserisci l'indirizzo MAC nella scheda del server (sezione Wake-on-LAN), poi scegli Sveglia dal menu del server. Funziona nella stessa rete locale.

Come elimino tutti i miei dati?

Elimina i server dall'app, poi disinstallala. Non conserviamo copie da nessuna parte: vedi la Privacy.
